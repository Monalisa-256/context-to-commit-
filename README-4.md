# Executable examples

The [reading queue exercise](reading_queue/README.md) is the reference implementation for [MASTERPLAN.md](../MASTERPLAN.md). It provides a known failure, a working correction, test evidence, and a session handoff that can be inspected without a coding agent subscription.

The example is intentionally local and supervised. It does not claim to isolate untrusted code, connect automatically to external coding agents, or operate as a production service.
